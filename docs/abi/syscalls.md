state in this kernel on 2026-09-29 and the phase of [phases.md](phases.md) that
owns it. Generated by `scripts/dev/make-syscall-table.py` from the kernel's own
rows (`kernel/abi/linux/*.c`), so the
*state* column is read, not remembered; phase A1 turns this table into the checked
registry the dispatcher reads.
