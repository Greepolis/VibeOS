# S4: vsh

Phase S4 of the shell ([design.md](design.md)): the language and the line
editor of `/usr/bin/vsh`. The grammar below was agreed with the project's owner
on 2026-11-21, before the parser was written.

## What it looks like

```
set nome = "Andrea"
set file = (a.txt "con spazio.txt" c.txt)
export EDITOR = nano
echo "ciao $nome, ${file[0]}, sei in %CD%"

if $n >= 10 && $nome != "root" {
    echo grande
} else if $f ~ *.txt {
    echo testo
} else {
    echo altro
}

if (grep -q errore log.txt) { echo trovato }

for f in *.c { cc -c $f }
while $n > 0 { set n = $(( $n - 1 )) }

func saluta chi {
    global ultimo = $chi
    echo "ciao $chi"
    return 0
}

ls -l | grep txt > out.log 2>&1 &
make && echo ok || echo no
try rm forse.txt
```

## The grammar

```
script    = { statement terminator } ;
terminator= NEWLINE | ";" ;
statement = set | global | export | errors | if | for | while | func | return
          | "break" | "continue" | chain [ "&" ] ;

set       = "set" NAME "=" value ;
global    = "global" NAME "=" value ;
export    = "export" NAME [ "=" value ] ;
errors    = "set" "-e" ( "on" | "off" ) ;
value     = word | "(" { word } ")" ;

if        = "if" cond block { "else" "if" cond block } [ "else" block ] ;
for       = "for" NAME "in" { word } block ;
while     = "while" cond block ;
func      = "func" NAME { NAME } block ;
return    = "return" [ word ] ;
block     = "{" script "}" ;

cond      = andc { "||" andc } ;
andc      = notc { "&&" notc } ;
notc      = [ "!" ] atom ;
atom      = word [ cmpop word ] | "(" chain ")" ;
cmpop     = "==" | "!=" | "<" | "<=" | ">" | ">=" | "~" | "~~" ;

chain     = pipeline { ( "&&" | "||" ) pipeline } ;
pipeline  = [ "try" ] command { "|" command } ;
command   = { NAME "=" word } word { word | redirect } ;
redirect  = [ DIGIT ] ( ">" | ">>" | "<" ) word | DIGIT ">&" DIGIT ;

word      = { text | "'...'" | '"..."' | "$" NAME | "${" NAME [ "[" n "]" ] "}"
          | "%" NAME "%" | "$(" script ")" | "$((" arith "))" | "$?" } ;
```

## The rules

- **No word splitting.** `$x` is one word whatever it holds. Only a list expands
  to several.
- **`<` and `>`** compare after `if` and `while` and redirect in a command,
  which is why a command used as a condition goes in parentheses.
- **Comparison.** Numeric if both sides are numbers, otherwise on the text, and
  `==` keeps case. `~` matches a pattern; `~~` matches it ignoring case.
- **`%x%`** expands only if `x` exists, so `date +%d%m%Y` keeps working.
- **Backslash** escapes only before a space, a quote, `$`, `\` and a newline, so
  `C:\Users\vibe` needs no doubling.
- **Errors.** A script stops at its first failure and an interactive shell does
  not. Conditions and `try` are exempt, and `set -e off` turns it off. A pipeline
  fails if a stage fails, except a stage ended by SIGPIPE: `yes | head` is not
  an error.
- **Scope.** A variable set in a function is local to it; `global` sets it
  outside.
- **A bare `x=1` is refused**, with a message suggesting `set x = 1`. `X=1 cmd`
  sets the environment of that one command.
- **Case.** Builtins and aliases ignore it; files follow the case policy.
- **Builtins:** `cd`, `pwd`, `echo`, `set`, `unset`, `export`, `alias`,
  `unalias`, `exit`, `source`, `jobs`, `fg`, `bg`, `wait`, `kill`, `history`,
  `type`, `true`, `false`.
