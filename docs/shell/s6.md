# S6: cmd

Phase S6 of the shell ([design.md](design.md)): Wine 9.0's `cmd.exe`, run by the
NT personality.

| Step | What | State |
|---|---|---|
| 1 | msvcrt: the wide-string calls cmd uses | done |
| 2 | cmd's own entry point, in place of mingw's C runtime start | to do |
| 3 | The rest of msvcrt: files, `fwprintf`, `signal` and the like | to do |
| 4 | kernel32: console, environment, dates, file operations | to do |
| 5 | advapi32, user32, ntdll, and a small shell32 | to do |
| 6 | cmd at boot, against what it prints under Wine | to do |

Measured on 2026-11-22, cmd imports about 78 functions our DLLs do not export:
kernel32 36, msvcrt 33, advapi32 3, shell32 3, user32 2, ntdll 1. Some of the
msvcrt ones are only mingw's start-up code, which is what step 2 removes.

## Step 1

`towupper`, `_wcsupr`, `_wcslwr`, `_wcsrev`, `wcscspn`, `wcstol`, `wcstoul` and
`_wsplitpath`, in `user/win/msvcrt/crt_core.c`. The number parsers are compared
with glibc's on random strings, clamped to msvcrt's 32-bit `long`. A recent glibc
reads C23's `0b` prefix and msvcrt does not, so those strings are left out of the
comparison. Case: `win-msvcrt-cmd.txt`.
