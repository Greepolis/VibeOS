#
#  1. a semaphore's read takes the whole count. Expect "a semaphore gives one at
#     a time".
#  2. the largest count is one less. Expect "one more does not: no room,
#     readable and not writable" (the count overflows past the largest).
#  3. the value past the largest is accepted. Expect "the value past the
#     largest count, a short buffer, an unknown flag: EINVAL".
#  4. a reader at zero is told EAGAIN whether or not it may wait. Expect "and
#     waits at zero".
#  5. writable means readable. Expect "one more does not: no room, readable and
#     not writable".
#
# Target source: kernel/abi/files/eventfd.c
# Run: SABOTAGE_VERIFY="bash scripts/dev/verify-host-quick.sh" python3 scripts/dev/sabotage.py kernel/abi/files/eventfd.c scripts/dev/cases/abi-eventfd.txt
