# inotify (kernel/abi/linux/inotify.c, docs/abi/ L4 step 6), proved by
# t_inotify in tests/kernel/linux_abi_tests.c.
#
#  1. the directory hears nothing. Expect "create, open, modify, close-write -
#     in order, each named".
#  2. the node itself hears its directory's events. Expect "MOVED_FROM and
#     MOVED_TO to the directory with one cookie; the file itself hears
#     MOVE_SELF and only that" (it asked for MOVED_* too, and is not told).
#  3. a deleted node keeps its watch. Expect "unlink: ATTRIB to the file,
#     DELETE to the directory, DELETE_SELF and IGNORED".
#  4. a full queue drops silently. Expect "an overflow ends the queue with
#     IN_Q_OVERFLOW, wd -1".
#  5. a read too short for a record returns nothing. Expect "a buffer shorter
#     than the next record is EINVAL".
#  6. a name is not padded. Expect "a record's name is padded to a multiple of
#     the header".
#  7. IN_MASK_CREATE replaces. Expect "a second watch on the same file is the
#     same wd, or EEXIST under IN_MASK_CREATE".
#  8. rm_watch says nothing. Expect "rm_watch queues IN_IGNORED, and nothing
#     after it".
#  9. a directory's DELETE_SELF says it is one. Expect "ATTRIB with IN_ISDIR;
#     MOVE_SELF and DELETE_SELF bare; then IGNORED" (LTP's inotify04).
# 10. a link count goes to the directory too. Expect the same: the unlink in
#     it would add "1 4 x" (inotify04).
#
# Target source: kernel/abi/linux/inotify.c
# Run: SABOTAGE_VERIFY="bash scripts/dev/verify-host-quick.sh" python3 scripts/dev/sabotage.py kernel/abi/linux/inotify.c scripts/dev/cases/abi-inotify.txt
