# Limits, priorities and personality (kernel/abi/linux/limits.c, docs/abi/ L2
# step 4). Host test: t_limits in tests/kernel/linux_abi_tests.c.
#
#  1. a soft limit above the hard one is accepted. Expect "a soft limit above
#     the hard one is EINVAL".
#  2. NOFILE may be raised past the descriptor table. Expect "nobody raises
#     NOFILE past what the table can hold".
#  3. RLIMIT_NOFILE is stored and the table not told. Expect "setrlimit(
#     RLIMIT_NOFILE) is the table's limit".
#  4. RLIMIT_CPU is stored and nothing armed. Expect "SIGXCPU when it has".
#  5. the superuser is held to RLIMIT_NPROC. Expect "the superuser is not held
#     to RLIMIT_NPROC".
#  6. RLIMIT_NPROC counts nothing. Expect "a user at RLIMIT_NPROC cannot fork".
#  7. a user may raise a hard limit. Expect "nor raise a hard limit".
#  8. prlimit64 lets a user reach another user's process. Expect "a user may
#     not reach the superuser's".
#  9. getpriority answers nice itself. Expect "getpriority answers 20 - nice".
# 10. a user may lower its nice with no allowance. Expect "may not lower its
#     own nice without RLIMIT_NICE".
# 11. a user may renice another user's task. Expect "nor touch the
#     superuser's".
# 12. personality's query changes the personality. Expect "personality is kept
#     and read back".
#
# Target source: kernel/abi/linux/limits.c
# Run: SABOTAGE_VERIFY="bash scripts/dev/verify-host-quick.sh" python3 scripts/dev/sabotage.py kernel/abi/linux/limits.c scripts/dev/cases/abi-limits.txt
