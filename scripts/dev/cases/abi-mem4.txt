# madvise, mincore, mlock and mremap (docs/abi/ L3 step 4). Host test:
# t_memory_calls in tests/kernel/linux_abi_tests.c.
#
#  1. MADV_DONTNEED leaves the page as it was
#  2. a shared page is discarded like a private one
#  3. a locked page is discarded
#  4. advice that changes what fork does is taken
#  5. madvise does not look for a hole
#  6. mincore calls a page in swap resident
#  7. mincore does not judge its vector (red because the host test then stores
#     through a pointer that is nobody's and dies there - which is what the
#     check is for, and is not the same as an expectation failing)
#  8. mlock locks nothing
#  9. mlock2 takes any flag
# 10. mremap grows over what is after the mapping
# 11. mremap moves without being allowed to
# 12. mremap leaves the old range described
# 13. mremap takes a range across two mappings
# 14. a shared mapping grows with private pages
#
# Target source: kernel/abi/linux/mm.c
# Run: SABOTAGE_VERIFY="bash scripts/dev/verify-host.sh build-gcc-Release" python3 scripts/dev/sabotage.py kernel/abi/linux/mm.c scripts/dev/cases/abi-mem4.txt
