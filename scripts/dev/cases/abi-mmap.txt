# mmap by the rules, docs/abi/ L3 step 1 (kernel/abi/linux/mm.c), proved by the
# handlers' host tests in tests/kernel/linux_abi_tests.c on the fake kernel's
# real page tables.
#
# Each case names the expectation it should fail. Three went NOT RED first:
#
#  - "MAP_FIXED leaves what was there". The address-space layer releases the
#    page a mapping replaces, so the pages were right without the handler's
#    unmap. What the unmap is for is the region list, which refuses the new
#    region as an overlap; the test maps over a mapped page and a free one now
#    and asks mprotect about the second.
#  - "a file mapping ignores its offset". The test file's pattern repeated
#    every 256 bytes, so the byte at offset 4096 was the byte at 0.
#  - "anything with a descriptor can be mapped" goes red by crashing - the
#    handler calls a read operation a pipe does not have - and not by the
#    expectation that names it. Kept, and counted as that kind of red.
#
# Target source: kernel/abi/linux/mm.c
# Run: SABOTAGE_VERIFY="bash scripts/dev/verify-host.sh build-gcc-Release" python3 scripts/dev/sabotage.py kernel/abi/linux/mm.c scripts/dev/cases/abi-mmap.txt
