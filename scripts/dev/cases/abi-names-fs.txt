# What docs/abi/ L1 step 5 changed in kernel/abi/linux/fs.c, proved by the
# handlers' host tests in tests/kernel/linux_abi_tests.c.
#
#  1. every filesystem is device 0. Expect "two filesystems are two devices".
#  2. mkdir does not tell the filesystem the mode. Expect "mkdir keeps the mode
#     it was given".
#  3. mkdir does not apply the umask. Expect "less the umask".
#  4. unlinkat refuses AT_REMOVEDIR, as it did before the step. Expect "and
#     unlinkat(AT_REMOVEDIR) is rmdir".
#  5. a descriptor on no filesystem is walked anyway. Expect "fchmod of a pipe
#     is EINVAL".
#  6. AT_EMPTY_PATH is not honoured by the calls that walk. Expect "fchownat
#     with AT_EMPTY_PATH is fchown".
#
# Target source: kernel/abi/linux/fs.c
# Run: SABOTAGE_VERIFY="bash scripts/dev/verify-host.sh build-gcc-Release" python3 scripts/dev/sabotage.py kernel/abi/linux/fs.c scripts/dev/cases/abi-names-fs.txt
