# The Linux socket calls (kernel/abi/linux/net.c, docs/abi/ L5), proved by
# t_sock_bsd and t_unix in tests/kernel/linux_abi_tests.c.
#
#  1. rights with no room are given back silently. Expect "a receiver with no
#     control buffer: MSG_CTRUNC".
#  2. a right that is not open is skipped. Expect "a descriptor that is not open
#     is EBADF".
#  3. accept4's SOCK_NONBLOCK is ignored. Expect "accept4's SOCK_NONBLOCK".
#  4. every refused option is ENOPROTOOPT. Expect "IP asked for a level it has
#     not - EOPNOTSUPP to get" (LTP's getsockopt01).
#  5. accept judges the buffer before asking whether the socket listens.
#     Expect "accept on a stream that does not listen is EINVAL before its bad
#     buffer" (LTP's accept01).
#  6. getsockname takes a null length. Expect "getsockname with no length is
#     EFAULT". NOT RED the first time, and not for the test's sake: the anchor
#     matched the same condition in linux_sa_out first, so the case broke a
#     different line; it carries the comment after it now.
#  7. MSG_ERRQUEUE reads the ordinary queue; 8. a stream's recvfrom judges a
#     source it never writes. Expect "MSG_ERRQUEUE finds nothing; a stream's
#     recvfrom writes no source" (LTP's recv01 and recvfrom01).
#
# Target source: kernel/abi/linux/net.c
# Run: SABOTAGE_VERIFY="bash scripts/dev/verify-host-quick.sh" python3 scripts/dev/sabotage.py kernel/abi/linux/net.c scripts/dev/cases/abi-net-l5.txt
