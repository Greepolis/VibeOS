# The signal calls of docs/abi/ L2 step 2, and rt_sigreturn reading Linux's
# frame back. Host test: t_signals_l2 in tests/kernel/linux_abi_tests.c.
#
#  1. rt_sigreturn does not put the vector registers back. Expect "and puts
#     back its mask and its vector registers".
#  2. sigaltstack moves the stack a handler is running on. Expect "it cannot be
#     changed from on it".
#  3. an alternate stack too small for a frame is accepted. Expect "one smaller
#     than MINSIGSTKSZ is refused".
#  4. rt_sigpending reports what is pending, blocked or not. Expect "and only
#     the blocked ones".
#  5. rt_sigsuspend forgets the program's own mask. Expect "rt_sigsuspend waits
#     under its mask".
#  6. rt_sigtimedwait with a zero time waits. Expect "a zero wait is EAGAIN".
#  7. a program queues a signal claiming kill sent it, to another process.
#     Expect "but may not claim kill sent it".
#  8. kill's signal says tkill sent it. Expect "the siginfo says kill sent it".
#  9. a thread's id finds no process. Expect "rt_sigqueueinfo and kill find a
#     process by one of its threads' ids".
# 10. a signal to a process on its way out is the sender's error. Expect "a
#     signal to a process that is exiting is not the sender's error".
# 11. tgkill looks up an id that is not positive. Expect "tgkill refuses an id
#     that is not positive".
# 12. rt_sigaction takes a sigset of any size. Expect "rt_sigaction and
#     rt_sigprocmask refuse a sigset that is not eight bytes".
#

# Run: SABOTAGE_VERIFY="bash scripts/dev/verify-host-quick.sh" python3 scripts/dev/sabotage.py kernel/abi/linux/sig.c scripts/dev/cases/abi-signal-calls.txt
