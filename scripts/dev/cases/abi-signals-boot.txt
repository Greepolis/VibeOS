# Signals on the machine (docs/abi/ L2 step 2): what the architecture does for
# a fault a program handles and for a child that ends. Gate: SIGNAL.ELF
# (tests/linux/musl_signal.c) prints SIG_L2_OK only if every check held, and
# the gate asserts it (signal_l2_checks_failed).
#
#  1. a fault never reaches the program's handler. Expect the musl program to
#     die of its SIGSEGV: signal_l2_checks_failed, with an unexpected fault.
#  2. SIGCHLD is never raised. Expect signal_l2_checks_failed: sigtimedwait for
#     SIGCHLD times out.
#  3. the null page reads as present to the program, because the kernel's
#     identity map is there. Expect signal_l2_checks_failed: SEGV_ACCERR where
#     Linux says SEGV_MAPERR.
#
# Target source: kernel/arch/x86_64/task_life.c
# Run: SABOTAGE_VERIFY="bash scripts/dev/verify-boot.sh" python3 scripts/dev/sabotage.py kernel/arch/x86_64/task_life.c scripts/dev/cases/abi-signals-boot.txt
