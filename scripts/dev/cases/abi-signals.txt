# Signal delivery as Linux does it (docs/abi/ L2 step 2): the frame is a
# return address, a ucontext and a siginfo, with the vector registers above
# them; the alternate stack; the flags a handler is installed with; and a fault
# offered to the program. Host test: t_signals_l2 in tests/kernel/linux_abi_tests.c.
#
#  1. the saved rip is not the interrupted one. Expect "the ucontext holds the
#     interrupted registers by Linux's names".
#  2. the handler is not handed the siginfo. Expect "its arguments are the
#     signal, the siginfo and the ucontext".
#  3. the vector registers are not saved. Expect "and the vector registers,
#     64-aligned, where fpstate says".
#  4. SA_ONSTACK is ignored. Expect "SA_ONSTACK delivers on it".
#  5. a frame on the alternate stack starts at its top again. Expect "already on
#     it, the next frame goes below the one in use".
#  6. the handler returns to sigsuspend's temporary mask. Expect "and the
#     handler returns to the program's own mask".
#  7. a fault the program blocks is raised against it. Expect "and one the
#     program blocks, as Linux forces it - nothing left pending behind it". The
#     task is killed either way - delivery skips a blocked signal - so the
#     first run of this case went NOT RED; what the check keeps from happening
#     is the signal left pending in a task that is about to die.
#  8. SA_NODEFER is ignored. Expect "SA_NODEFER leaves the signal unblocked".
#  9. a fault on a page that is there is reported as one that is not. Expect
#     "a present page refused is SEGV_ACCERR".
# 10. SS_AUTODISARM is ignored. Expect "and disarms the stack while a handler
#     is on it".
# 11. SA_RESETHAND clears SA_SIGINFO, as an older Linux did. Expect "and
#     SA_RESETHAND leaves SA_SIGINFO as it was".
#
# Target source: kernel/abi/linux/signal.c
# Run: SABOTAGE_VERIFY="bash scripts/dev/verify-host-quick.sh" python3 scripts/dev/sabotage.py kernel/abi/linux/signal.c scripts/dev/cases/abi-signals.txt
