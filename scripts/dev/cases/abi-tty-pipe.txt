# step 7), proved through poll by tests/kernel/linux_abi_tests.c.
#
#  1. a pipe nobody can write is not readable. Expect "a pipe nobody can write
#     any more is readable - end of file - and hung up".
#  2. an empty pipe is readable. Expect "an empty pipe: nothing to read, room
#     to write".
#
# Target source: kernel/abi/files/pipefile.c
# Run: SABOTAGE_VERIFY="bash scripts/dev/verify-host.sh build-gcc-Release" python3 scripts/dev/sabotage.py kernel/abi/files/pipefile.c scripts/dev/cases/abi-tty-pipe.txt
