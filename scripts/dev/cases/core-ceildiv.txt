#     declare. Expect the test at UINT64_MAX and UINT64_MAX - 510.

### the rounding adds before it divides
--- old
    return n / unit + ((n % unit) != 0u ? 1u : 0u);
+++ new
    return (n + unit - 1u) / unit;
