# X-P4: exactly one function may name an interpreter path (check-exec-layering.sh).

# in a comment two thousand lines from the function ("[EXEC] interpreter

# unmodified check against the tree at HEAD before this fix - it was already red and
# nobody had run it. Fixed by skipping comment lines; this case is the proof in both
# directions: a second *code* path outside the function must still fail, and the
# existing log-example comment must not.

# check can no longer find what it guards. It printed FAIL and exited 0 on that

# red on the fixed one.

# Run: SABOTAGE_VERIFY="bash scripts/dev/check-exec-layering.sh" python3 scripts/dev/sabotage.py kernel/arch/x86_64/task_life.c scripts/dev/cases/core-exec-layering.txt
