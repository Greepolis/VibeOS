# C2 - every module says whether it is broken, and the ways that goes wrong.
#
# The three observability failures docs/core/phases.md names, each of which this
# project has shipped at least once, each caught by a check rather than the boot
# gate - and, until this file had cases in it, each *claimed* to be caught without
# anybody having made it fail. The cases below are the proof, run against the check
# named beside each.
#
#  1. A counter declared and never incremented. VIBEOS_BLK_TIMEOUT was defined,
#     printed, asserted by the gate and produced by no driver - green by
#     construction. check-counters-produced.py matches every reported counter
#     against every ++ in the tree; the first case removes the only increment of
#     the network stack's sock_stale_parent and it must name that counter.
#
#  2. A must-be-zero printed and not asserted. The ring-3 ABI line said
#     "mmap/mprotect/munmap wrong" for a session while the gate stayed green,
#     because the line was collected and never asserted on. check-mustbezero-
#     asserted.py holds every [X] MUSTBEZERO field to an assertion; the second
#     case detaches the gate's read of sock_stale_parent and it must name it.
#
#  3. A witness that reports a count instead of an object. A count says how often;
#     found=0 freed_by=0 stayed unexplained for a phase because the poison report
#     gave a number, not which frame, which word, and who freed it. The [MBZ] line
#     prints the first offender and the value that tripped it *on the same line*,
#     and the gate requires both: the third case removes the witness from the line
#     and the boot must go red (mbz_counters_missing), so a failure can never again
#     arrive as a bare number.
#
# The network module's must-be-zero is two slot-index ABA counters the stack must
# keep at zero: sock_stale_parent (a TCP child whose listener slot was reused
# mid-handshake, H-028) and sock_fd_aba (a blocking accept/connect/recvfrom whose
# descriptor a sibling thread closed and reused, M-020). Both are demonstrated able
# to be non-zero rather than trusted: test_inet_tcp_accept_aba drives
# sock_stale_parent.
#
# Target source: kernel/net/inet.c (case 1), scripts/qemu-cli-smoke-linux.py (case 2), kernel/arch/x86_64/arch_hw.c (case 3)
# Run case 1: SABOTAGE_VERIFY="python3 scripts/dev/check-counters-produced.py" python3 scripts/dev/sabotage.py kernel/net/inet.c scripts/dev/cases/core-observability.txt
# Run case 2: SABOTAGE_VERIFY="python3 scripts/dev/check-mustbezero-asserted.py" python3 scripts/dev/sabotage.py scripts/qemu-cli-smoke-linux.py scripts/dev/cases/core-observability.txt
# Run case 3: SABOTAGE_VERIFY="bash scripts/dev/verify-boot.sh build-clang-Release" python3 scripts/dev/sabotage.py kernel/arch/x86_64/arch_hw.c scripts/dev/cases/core-observability.txt
