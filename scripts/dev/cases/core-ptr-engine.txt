# C4 stage 2b: the descriptor engine itself (check_pointers in dispatch.c).
#
# Every row's pointer arguments are only as good as the loop that reads them. The
# ring-3 test program writes from a kernel address (0x4000000) and prints "kernel
# pointer correctly rejected" only if the kernel refused; the boot gate asserts that
# line (reason kernel_pointer_not_rejected). Before this change nothing asserted it.
#
# 1. the engine judges nothing: every descriptor passes;
# 2. the engine skips every descriptor whose length comes from another argument
#    (write, read, sendto ... - the buffers), so the bad write passes untouched.
#
