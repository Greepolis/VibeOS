# An ext2 directory entry's name stays inside its own record (M-049), proved by
# the host test.
#
#  (Both scans - readdir and lookup - read their entries through one function
#  since E4-014, dir_entry_at, so one bound serves both.)
#  1. readdir without the bound - the state M-049 found: a name_len larger than
#     the record copies the records after it and, at the end of a block, up to
#     254 bytes of the kernel stack into an ordinary readdir();
#  2. the bound checked against the block instead of the record, which is what
#     lookup did: inside the buffer, and still into the next record.
#
# Target source: kernel/fs/ext2.c
# Run: python3 scripts/dev/sabotage.py kernel/fs/ext2.c scripts/dev/cases/fs-ext2-names.txt

--- old

### ext2 never keeps what it read (#108)
