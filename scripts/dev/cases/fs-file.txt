# Open file descriptions (kernel/fs/file.c, docs/abi/ A3), proved by the host test
# in tests/kernel/fdtable_tests.c.
#
#  1. the last put does not run the type's release: a pipe end is never given
#     back, a written file never committed. Expect "the last put releases it".
#  2. a put with nothing to put is clamped instead of counted. Expect "a put with
#     nothing left is counted".
#  3. a slot is handed out while its release is still running - the refcount
#     alone decides it is free. Expect "a slot being released is not handed out".
#  4. a description's locks outlive it (docs/abi/ L1 step 6). Expect, from
#     linux_abi_tests.c, "closing the last gives it back".
#
# Target source: kernel/fs/file.c
# Run: SABOTAGE_VERIFY="bash scripts/dev/verify-host.sh build-gcc-Release" python3 scripts/dev/sabotage.py kernel/fs/file.c scripts/dev/cases/fs-file.txt
