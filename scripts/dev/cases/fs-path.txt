# Paths (kernel/fs/path.c, docs/abi/ A4), proved by the host tests in
# tests/kernel/path_tests.c and the Linux handlers' in linux_abi_tests.c.
#
#  1. ".." climbs above the root. Expect "normalize(root=/jail, ...)" - a process
#     given a root must not walk out of it.
#  2. a component longer than NAME_MAX is accepted. Expect "a component over
#     NAME_MAX is ENAMETOOLONG".
#  3. a file used as a directory is looked up anyway, so /file/x reports ENOENT
#     rather than ENOTDIR. Expect "a file used as a directory is ENOTDIR".
#  4. a relative path ignores the working directory - what every path was until
#     A4. Expect "normalize(root=/, cwd=/usr, bin)" and the handlers' "a relative
#     open starts there".
#
# The walk's symbolic links (L1):
#
#  5. no bound on links followed. Expect "a cycle is ELOOP, not a hang" - red
#     with ENAMETOOLONG, not HUNG: every splice leaves a '/' behind, so a cycle
#     grows the rest of the path until the pending buffer refuses it. The
#     buffer is a second line of defence; the bound is what makes the answer
#     the right errno.
#  6. an absolute target continues from the link's directory instead of the
#     root. Expect "an absolute link starts again from the root".
#  7. the rest of the path always moved up, never down. Expect "a target
#     shorter than the link keeps the rest of the path intact" - the move
#     overlaps itself and copies bytes it has already overwritten.
#  8. NOFOLLOW ignored. Expect "NOFOLLOW answers with the link itself".
#  9. a trailing slash on a file accepted. Expect "a trailing slash asks for a
#     directory".
#
# Target source: kernel/fs/path.c
# Run: SABOTAGE_VERIFY="bash scripts/dev/verify-host.sh build-gcc-Release" python3 scripts/dev/sabotage.py kernel/fs/path.c scripts/dev/cases/fs-path.txt
