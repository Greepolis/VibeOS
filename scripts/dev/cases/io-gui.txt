# (tests/kernel/gui_tests.c). The randomised model and the threads are
# io-gui-torture.txt; the boot gate's GUI assertions are io-gui-boot.txt.
#
#  1. the minimum screen is not enforced: a 30-pixel-high screen is accepted.
#     Expect the refusal-by-name test. With the clamps now comparing before
#     they add, the fill no longer runs off the buffer - see the note below;
#  2. the canary is never written: expect the first repaint to find all 512
#     words broken;
#  3. the canary is not examined on the repaint: expect guard_checks and the
#     flipped-word test;
#  4. the wrap on the last row writes before it scrolls - the behaviour before
#     C7, which dropped the character: expect the wrap test, and term_overrun,
#     because the write now lands one row past the grid and is refused;
#  5. a lock the caller already holds is treated as taken: expect the
#     reentrancy test - a panic printing from inside the GUI would wait on its
#     own core;
#  6. putc before init is accepted into the grid: expect the "ignored" test.
#
# S7's terminal (docs/shell/s7.md), each expecting a test in vt_tests.c's
# test_screen_full:
#  7. an empty cell ends the row on screen, as before S7: "a character past an
#     erased cell is drawn, the erased cell is not";
#  8. erasing ignores the pen: "erasing leaves the pen's background";
#  9. a newline ignores the scroll region: "a newline at the region's bottom
#     scrolls the region";
# 10. the alternate screen does not keep the main one: "and the main screen
#     back, as it was";
# 11. a 24-bit colour is read one place off: "a 24-bit foreground on a
#     256-colour background".
#
# Not a case, and why: reverting clip() to the old `x + w > g_w` clamp goes
# NOT RED here, because init now refuses every geometry on which the
# subtraction underflows. The two are defences in depth for the same defect;
# the case that removes the first (1) is the one that can be observed. Removing
# both reproduces the pre-C7 state, which the torture's small-screen rounds

# old defect rather than either defence.
