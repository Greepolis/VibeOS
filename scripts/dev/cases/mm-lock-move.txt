# A locked page, and a page moved (docs/abi/ L3 step 4). Host test:
# t_memory_calls in tests/kernel/linux_abi_tests.c, over this layer.
#
#  1. a locked page is paged out like any other
#  2. the copy a write fault makes loses the lock
#  3. a moved page takes a new reference and leaves the old mapping
#  4. a moved page is not removed from where it was
#
# Target source: kernel/mm/vmspace.c
# Run: SABOTAGE_VERIFY="bash scripts/dev/verify-host.sh build-gcc-Release" python3 scripts/dev/sabotage.py kernel/mm/vmspace.c scripts/dev/cases/mm-lock-move.txt
