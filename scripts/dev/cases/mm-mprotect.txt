# Target source: kernel/mm/vmspace.c (vibeos_vmspace_mapped, which mprotect asks since A2)
#
# mprotect on an address space some of whose pages are in swap. svc-reclaim
# makes every block read-only before reading it back, and by then most of the
# oldest are on disk. Run with SABOTAGE_VERIFY=scripts/dev/verify-boot.sh.
#
#  1. the range check asks whether each entry is present, as it did before
#     2026-09-27. Expect reclaim_load_failed: "mprotect refused block".
#
# Not a case: releasing the address-space lock before the page-table pass,
# which is the race with fork this change closed. A fork has to read an entry
# in the few instructions between the list update and the narrowing, and one
# boot does not make that happen; a case that goes NOT RED here would say
# nothing about the lock. Recorded as untested rather than as covered.

### mprotect refuses a page in swap
--- old
    return e && (*e & (PTE_PRESENT | VIBEOS_PTE_SWAPPED)) != 0u;
+++ new
    return e && (*e & PTE_PRESENT) != 0u;
