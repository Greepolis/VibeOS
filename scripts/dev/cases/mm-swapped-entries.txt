# M-063: a swapped-out entry is a mapping. Page-out and page-in were proved on
# their own; nothing asked what munmap, teardown, mprotect or fork do to a page
# that is on disk, and the first boot to force reclaim on a machine showed all
# four ignoring it - and page-in making every page user-writable, and taking a
# second reference that leaked one frame per page brought back (764 in a boot).
# Proved by test_swapped_entries_are_mappings and test_swap_round_trip.
#
# Not a case: clone_one starting again when a page is swapped out *during* the
# conversion loop. That is a race with reclaim on another core, which no host
# test produces on demand.
