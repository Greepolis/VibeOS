# What the stack says a socket can do without waiting (kernel/net/inet.c,
# vibeos_inet_ready, docs/abi/ L4 step 1), as Linux's tcp_poll says it. Host
# tests: test_inet_ready in tests/kernel/kernel_tests.c, a peer simulated
# through every state, and t_event_loops in tests/kernel/linux_abi_tests.c.
#
#  1. a listener is ready with nobody waiting - "always ready" again, what
#     sent nc spinning in poll
#  2. a socket nobody connected is not hung up
#  3. the peer's FIN is not readable, so a program waiting for the end of the
#     stream waits for ever
#  4. a reset says nothing extra: no error, no hangup
#
# Target source: kernel/net/inet.c
# Run: SABOTAGE_VERIFY="bash scripts/dev/verify-host-quick.sh" python3 scripts/dev/sabotage.py kernel/net/inet.c scripts/dev/cases/net-inet-ready.txt
