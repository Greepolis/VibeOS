# M-020: a socket syscall that waits re-verifies its socket after every wake
# (kernel/abi/linux/net.c), proved by check-net-stable.py.
#
#  1. recvfrom stops re-verifying - the state an external review found it in on
#     2026-09-24, a phase after the tracker called M-020 fixed: expect
#     "hw_sys_recvfrom waits holding a descriptor and never calls hw_sock_stable";
#  2. the same for accept, one of the three the original fix did reach.
#
# The race itself is not reproduced - it needs a sibling thread closing and
# reusing the descriptor while the call waits. What is checked is the rule that
# makes it impossible, at every site, which is what was missing: three sites had
# it and the fourth was left to memory.
#
# Target source: kernel/abi/linux/net.c
# Run: SABOTAGE_VERIFY="python3 scripts/dev/check-net-stable.py" python3 scripts/dev/sabotage.py kernel/abi/linux/net.c scripts/dev/cases/net-sock-stable.txt
