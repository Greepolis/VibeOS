# The credential rules (docs/abi/ L2 step 1): kernel/sched/cred.c. Host test:
# t_credentials in tests/kernel/linux_abi_tests.c, through the Linux handlers.
#
#  1. the owner's bits do not decide for the owner (other's are used)
#  2. a supplementary group does not count
#  3. root's setuid leaves the saved id (a way back)
#  4. an unprivileged setuid takes any id
#  5. setreuid always leaves the saved id alone
#  6. setresuid lets an unprivileged process take an id it does not hold
#  7. setfsuid takes any id
#  8. setgroups is anybody's
#  9. -1 becomes root's filesystem id, so setfsuid(-1) - a question - answers
#     -1 the next time (L2 step 7, LTP's setfsuid02)
#
# Target source: kernel/sched/cred.c
