# The process-timer table (kernel/sched/ptimer.c, docs/abi/ L2 step 3). Host
# test: test_ptimer in tests/kernel/ptimer_tests.c.
#
#  1. a real timer fires a tick early. Expect "it does not fire with its time
#     not wholly gone".
#  2. a one-shot timer stays armed after it fires. Expect "and is disarmed
#     afterwards".
#  3. periods that went by between ticks are not counted. Expect "periods with
#     no tick to fire them are overruns".
#  4. a pending signal's overrun count is not kept. Expect "expiries that found
#     the signal pending are its overrun count".
#  5. kernel time counts for ITIMER_VIRTUAL. Expect "time in the kernel is not
#     ITIMER_VIRTUAL's".
#  6. a thread's CPU clock counts every thread of the process. Expect "another
#     thread's time is not its".
#  7. exec drops the interval timers too. Expect "exec drops POSIX timers and
#     keeps alarm".
#  8. the count of armed CPU-time timers is not kept, so the tick skips them.
#     Expect "and ITIMER_PROF counts it".
#  9. a full table takes a timer over. Expect "a full table refuses".
# 10. a timer due when the batch is full is lost. Expect "every timer fires, in
#     batches, none lost".
#
# Target source: kernel/sched/ptimer.c
# Run: SABOTAGE_VERIFY="bash scripts/dev/verify-host-quick.sh" python3 scripts/dev/sabotage.py kernel/sched/ptimer.c scripts/dev/cases/sched-ptimer.txt
