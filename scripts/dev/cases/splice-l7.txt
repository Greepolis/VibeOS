# splice, tee and vmsplice (docs/abi/ L7 step 5). Host tests: t_splice in
# tests/kernel/linux_abi_tests.c; the pipe's peek is in pipe_tests.c.
#
#  1. tee takes the bytes it copies. Expect "pipe to file: written at the
#     offset, and the pipe is empty after" - which then has nothing to write.
#  2. a file's offset is not moved. Expect "file to pipe: five bytes, and the
#     offset moves".
#  3. SPLICE_F_NONBLOCK waits. Expect "an empty pipe with SPLICE_F_NONBLOCK:
#     EAGAIN" (the host's fake would report the wait as a block).
#  4. an offset on a pipe is ignored. Expect "an offset on a pipe".
#  5. vmsplice waits to put in all of it. Expect "vmsplice of more than fits"
#     (the fake reports the wait as a block).
#  6. splice stops after one page. Expect "splice and tee of more than a page
#     move all of it".
#
# Target source: kernel/abi/linux/splice.c
# Run: SABOTAGE_VERIFY="bash scripts/dev/verify-host-quick.sh" python3 scripts/dev/sabotage.py kernel/abi/linux/splice.c scripts/dev/cases/splice-l7.txt
