# Linux x86-64 syscall numbers this kernel implements, and the names they carry.
#
# The authority for check-syscall-checks.py: every row in kernel/abi/linux/*.c must
# carry the number its name has here. A typo in a row's number is a *different
# syscall*, and nothing else in the tree would notice - the handler compiles, the
# table registers, and a program calling the right number gets ENOSYS.
#
# The numbers are from arch/x86/entry/syscalls/syscall_64.tbl, not from memory. The
# two at 1000 and above are VibeOS's own, outside the Linux number space on purpose,
# so they can never collide with a real syscall implemented later.
#
# Adding a syscall means adding its line here as well as its row: two independent
# statements of the same number, checked against each other.
